# Dev_Work_Dafna
My app started from a simple 0-10 counter, and progressed to being a counter with a few references to f1 drivers
Core features: a button that you press to count the numbers, buttons that play music when pressed
Dependencies:Flet (flet) – Creates the application interface, buttons, counter, keyboard shortcuts and layouts. Flet Audio (flet-audio) – Handles all the audio players and music playback.
how to run the code: python main.py
Any extra sources that you found on your own and used: music from Youtube, coding help from chat GPT
Easter eggs!: press control + f1 to get an oscar piastri easter egg, press control + f2 to see a kimi antonelli easter egg and lastly long press the + button on the screen for end credits.
